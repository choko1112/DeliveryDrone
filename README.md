# ドローン配達便

ファミコン風の横スクロール配達アクションです。ブラウザで遊べます(PCのキーボード専用)。

## 遊び方

- 移動: ←→ または A D
- はばたく: スペース / Z / ↑
- 音の切り替え: M

各ステージで、ドローンが吊るした荷物3個を家にゆっくり降ろして配達します。
敵のドローンに紐を横切られると荷物を落とします。敵の紐を切ると加点されます。全5ステージです。
